# Nyasara Website — Version 1

A premium, responsive static website concept for Nyasara: wall panels and interior decoration.

## Open locally

Double-click `index.html`, or run a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Included

- Responsive desktop and mobile design
- Custom Nyasara-inspired SVG emblem
- Hero, collections, brand story, process, professionals and lead sections
- Mobile navigation
- Scroll reveal interactions
- Demo lead form
- SEO description and semantic structure

## Before public launch

1. Replace the custom SVG with the exact approved transparent Nyasara logo asset.
2. Connect the lead form to Zoho CRM, Google Sheets, n8n, Formspree or another backend.
3. Add the final phone number, WhatsApp link, email, business address and social handles.
4. Replace conceptual collection visuals with real factory/product photography.
5. Add Privacy Policy, Terms, warranty/material specifications and installation coverage.
6. Configure domain, hosting, analytics, Meta Pixel and Google Search Console.

## Suggested technology path

- Phase 1: Static site on Cloudflare Pages / Netlify / Vercel
- Lead stack: Website form → n8n → Zoho CRM / Google Sheets → WhatsApp follow-up
- Phase 2: Product catalogue CMS, service-area logic, quotation workflow and customer portal
